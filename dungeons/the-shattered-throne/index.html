The Shattered Throne

The Shattered Throne is Destiny 2’s original dungeon, set in the haunting Ascendant spaces of the Dreaming City. Its gothic ruins and long paths helped establish the dungeon format.

Track The Shattered Throne runs

DungeonHub lets players explore The Shattered Throne activity reports and compare recorded Guardian completions. The Wish-Ender exotic quest is associated with the activity. As with other dungeons, a completed checkpoint report is not automatically a full run from the entrance.

Interested in a specific player? Search their Bungie Name in the tracker, select the dungeon, and open individual activity reports to see the available recorded information.

What DungeonHub shows

Shattered Throne completions, Wish-Ender quest context, and run details.

Completed activity: Bungie recorded a completion, which may include a checkpoint finish. Full start: The report explicitly identifies a run started from the beginning. Unknown: The report does not give enough evidence to classify the start. These distinctions help avoid misleading comparisons.
